# Sistema Inteligente de Ensalamento

Projeto desenvolvido para o Desafio UniSoma 2026.


## Instalação

pip install -r requirements.txt

## Execução

python app.py

## Funcionalidades

- Tratamento de dados
- Identificação de inconsistências
- Otimização do ensalamento
- Exportação para Excel
- Geração automática de PDF
